# Vastramay (vastramay-brutlism)

> **Vastramay** is a contemporary clothing e-commerce platform engineered with bold Neo-Brutalism aesthetics, Next.js 16 App Router, TypeScript, Tailwind CSS v4, and SCSS Modules.

---

## ⚡ Quick Start

```bash
# Install dependencies
npm install

# Start development server with Turbopack
npm run dev

# Run TypeScript strict check
npx tsc --noEmit

# Run ESLint
npm run lint

# Run optimized production build
npm run build
```

Open [http://localhost:3000](http://localhost:3000) to view the application.
